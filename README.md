# Wang Yi Heng | Portfolio

A responsive personal portfolio highlighting school projects, skills, and background.

## View locally

Open `index.html` in a browser. The page uses plain HTML and CSS and does not require a build step.

## Sections

- Introduction and short bio
- Skills and tools
- Progression Board, with links to the project landing page and controller view
- Landed Campus Companion source repository

The profile image loads from the public GitHub avatar URL. Replace the image URL in `index.html` if you want to use a different photo.
